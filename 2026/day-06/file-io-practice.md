Today I focused on understanding how Linux handles files—from creation to access and security.

🔧 File Creation Techniques
▪️Explored multiple ways to create files:
1. touch → create empty files quickly
2. echo → create files with content
3. cat → create and append content interactively
4. Redirection (>, >>) → overwrite vs append
5. Editors → vim, nano for advanced editing

📖 Reading File Content
▪️Learned different tools depending on use case:
1. cat → quick full output
2. less → scrollable, efficient for large files
3. head / tail → preview start or end of files
4. tail -f → real-time log monitoring

📂 Understanding File Types
▪️Identified key Linux file types:
1. Regular files (-)
2. Directories (d)
3. Symbolic links (l)

🔐 File Permissions & Ownership
▪️ Focused on access control and security:
1. ls -l → view permissions
2. chmod → modify permissions (numeric & symbolic)
3. chown → change ownership
4. Understood rwx for user/group/others
