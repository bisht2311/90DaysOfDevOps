Linux Command Cheatsheet

Process Management:
1. ps – Shows currently running processes
2. htop – Displays real-time process monitoring
3. pgrep – Find processes by name or PID
4. systemctl – Manage and control system services
5. kill – Terminate a process
6. nohup – Run a process in the background (continues after logout)
7. top – Display real-time system and process usage

File System:
1. mkdir / cp / mv – Create directory | Copy file | Move or rename file
2. touch – Create a new file
3. cat – Display/read file content
4. vim – Edit or write a file
5. chmod / chown – Change file permissions and ownership
6. rm – Delete a file | rm -r – Delete a directory
7. ls – List files and directories in the current directory

Networking:
1. ping – Check network connectivity
2. ip addr – Display IP address and network details
3. nslookup – Check DNS resolution
4. hostname -I – Show the system’s IP address
5. ip route – Show routing table of the system
6. netstat -tulnp – Show active ports and listening services
