❇️ Key Points:
Everything in Linux is a file or a directory.
Everything in Linux starts with a process.

➡️ Linux Architecture (ASKH)
Applications & Users → Shell → Kernel → Hardware

➡️ Linux File System
Everything starts from the root directory /. Important directories include:
/bin – user binaries
/sbin – system binaries
/etc – configuration files
/home – user directories
/tmp – temporary files
/var – logs and variable data

➡️ Linux Boot Process
Power On → BIOS → GRUB (bootloader) → Kernel → systemd (PID 1) → Login Screen

➡️ Program & Process
Program: Executable file stored on disk
Process: Program currently running in memory
Process States:
Running- The process is either currently executing
Sleeping- The process is waiting for resource to become available. 
Zombie- The process has finished execution but still has an entry in the process table
Dead- The process has been terminated.

⚠️ Commands mostly used:
top – monitor running processes
mkdir – create directories
grep – search inside files/logs/output
systemctl – manage system services
