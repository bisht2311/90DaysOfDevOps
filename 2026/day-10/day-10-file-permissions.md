🚀 Day 10/90 – #90DaysOfDevOps

Today I focused on Linux file operations and permissions, a key concept for managing secure and reliable systems.

🔹 Hands-on practice:
• Created files using touch, echo, and vim
• Read file contents with cat, head, and tail
• Explored permission structure: rwx (read, write, execute)
• Made scripts executable and tested execution
• Modified permissions (e.g., read-only, 640)
• Created directories with 755 permissions
• Tested real scenarios involving write/execute restrictions

🔹 Key learning:
Linux permissions define who can access or modify files, directly impacting system security and stability. Even small permission changes can significantly affect behavior.

💡 Takeaway:
Understanding and managing file permissions is essential for secure system administration and DevOps workflows.
